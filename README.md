# Arduino-Based Physics Projects

This repository contains a collection of Arduino-based projects developed as part of my undergraduate Physics training. The projects explore physical phenomena through sensors, electronic components, data acquisition, and experimental measurement.

## Projects

### 1. Electromagnetic Shielding

An experimental prototype designed to explore electromagnetic shielding using Arduino and electronic components. The system allows measurements to be collected under different configurations to study the effect of electromagnetic shielding.

**Main components:**

* Arduino
* Electromagnetic sensors
* Electronic components
* Data acquisition system

### 2. Seismic and Motion Detection

An Arduino-based system developed to detect mechanical vibrations and motion. The project uses sensors to measure changes in movement and explore the response of a system to external disturbances.

**Main components:**

* Arduino
* MPU6050 accelerometer/gyroscope
* Electronic components
* Data acquisition

## Technologies

* Arduino IDE
* Arduino
* C/C++
* Sensors and electronic instrumentation
* Experimental data acquisition

## Purpose

These projects allowed me to gain practical experience in designing, assembling, programming, and validating basic measurement systems, while connecting physical concepts with electronic instrumentation and data acquisition.
